Recruitee Careers Site API

Recruitee publishes each company's job offers through the Careers Site API at <company>.recruitee.com/api/offers/. Until 10 February 2027 it answers without a key; after that date every call needs a token that the company creates. Our index calls it for 1,100 companies a day and holds 19,848 open Recruitee jobs (20 November 2026).

the endpoint

The Recruitee job board endpoint

GET https://{company}.recruitee.com/api/offers/

  • Authentication: none until 10 February 2027. From then on every call needs the header X-Careers-Sites-Token with a token the company creates in Recruitee (Settings, Apps and plugins, Careers API tokens); calls without it get HTTP 401.
  • Format: JSON, an object with offers.
  • Pagination: none. One request returns every published offer.
ParameterWhat it does
departmentonly offers of this department, by name
tagonly offers with this tag, by name

Other endpoints of the same API:

  • GET https://{company}.recruitee.com/api/offers/{id or slug}: one offer

Source: Recruitee Careers Site API documentation. Checked 19 November 2026.

try it

Request and response

The board of TransPerfect, a Recruitee board from our index, as an example. Replace transperfect with the board you need.

curl

curl "https://transperfect.recruitee.com/api/offers/"

Python

import requests

r = requests.get("https://transperfect.recruitee.com/api/offers/", timeout=60)
r.raise_for_status()
for o in r.json()["offers"]:
    text = (o.get("description") or "") + (o.get("requirements") or "")  # both HTML
    print(o["id"], o["title"], o["location"], o["remote"], o["careers_url"])

which board

Finding a company's company subdomain

The company subdomain is the first part of <company>.recruitee.com. Many companies show the career site under their own domain; the job links then look like <domain>/o/<job-slug>, and the recruitee.com address still answers.

Our list of 1,171 companies using Recruitee shows the careers address of each one, and the address contains the identifier. The list is free to search and download as CSV.

in practice

What we learned reading it every day

  • Plan for 10 February 2027: from that date the API needs a token from each company. If you read career sites of companies that are not your customers, you will need another way to their jobs.
  • The job text is split into description and requirements; join them for the full text.
  • Dates are UTC but written as 2026-11-19 14:08:06 UTC, not ISO 8601. Parse them with that format.
  • Every offer also carries its application form settings and a mailbox address for applications. If you republish jobs, do not copy that address; link to careers_apply_url.
  • A big career site is large: TransPerfect's 770 offers are about 11 MB, mostly translations. Read it once a day.

questions

Frequently asked questions

Does the Recruitee job board API need an API key?

Not until 10 February 2027. From that date Recruitee requires an X-Careers-Sites-Token header, created by the company in its Recruitee settings, and answers HTTP 401 without it.

Is there a rate limit?

Recruitee documents no limit for the Careers Site API. One request returns all offers, so a daily read is one call per company. Keep your request rate modest.

Can I get all Recruitee jobs, from every company, at once?

No. The API answers for one company per request, and Recruitee publishes no list of its customers. Our index reads 1,100 Recruitee boards with open jobs every day (19,848 jobs on 20 November 2026); you can search all of them through our Apify actor or get them as a daily job data feed.

Is it allowed to use the Recruitee job board API?

The API exists so that companies can show their jobs on their own sites and so that job boards can list them. It returns only what the employer has published. Read Recruitee's documentation and terms for your use, keep request rates modest and link back to the original job for applications.
