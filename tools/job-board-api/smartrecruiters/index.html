SmartRecruiters Posting API

SmartRecruiters publishes every company's job postings through a public Posting API at api.smartrecruiters.com, in pages of up to 100. Our index calls it for 3,096 companies a day and holds 283,987 open SmartRecruiters jobs (20 November 2026).

the endpoint

The SmartRecruiters job board endpoint

GET https://api.smartrecruiters.com/v1/companies/{companyIdentifier}/postings

  • Authentication: none for public postings.
  • Format: JSON: offset, limit, totalFound and the postings in content.
  • Pagination: limit (up to 100) and offset. Read pages until one comes back with fewer than limit postings.
ParameterWhat it does
limit, offsetpage size (up to 100) and position
qfull-text search in the postings
country, region, cityfilter by location
locationTypeREMOTE, HYBRID, ONSITE or ANY
departmentfilter by department ID
releasedAfteronly postings published after this time
languageonly postings in this language

Other endpoints of the same API:

  • GET /v1/companies/{companyIdentifier}/postings/{postingId}: one posting with the full job ad in jobAd.sections, applyUrl, postingUrl and compensation when published

Source: SmartRecruiters Posting API documentation. Checked 19 November 2026.

try it

Request and response

The board of Ubisoft, a SmartRecruiters board from our index, as an example. Replace ubisoft2 with the board you need.

curl

curl "https://api.smartrecruiters.com/v1/companies/ubisoft2/postings?limit=100&offset=0"

Python

import requests

BASE = "https://api.smartrecruiters.com/v1/companies/ubisoft2/postings"
postings, offset = [], 0
while True:
    page = requests.get(BASE, params={"limit": 100, "offset": offset}, timeout=60).json()
    postings += page["content"]
    if len(page["content"]) < 100:
        break
    offset += 100

for p in postings[:3]:
    detail = requests.get(f"{BASE}/{p['id']}", timeout=60).json()
    sections = detail["jobAd"]["sections"]  # companyDescription, jobDescription, qualifications, additionalInformation
    print(p["id"], p["name"], p["location"]["fullLocation"], list(sections))

which board

Finding a company's company identifier

The company identifier is the first part of the path on the career page: careers.smartrecruiters.com/Ubisoft2 or jobs.smartrecruiters.com/Ubisoft2/<id> means Ubisoft2. The API accepts it in any letter case.

Our list of 3,189 companies using SmartRecruiters shows the careers address of each one, and the address contains the identifier. The list is free to search and download as CSV.

in practice

What we learned reading it every day

  • The list has no description. Each posting needs a second call to /postings/{id} for jobAd.sections, so a company with 4,000 postings is 40 list pages and 4,000 detail calls. Fetch details only for the postings you keep.
  • Large employers (Bosch, AECOM, Accor) list several thousand postings; stop paging when a page is short, not at a fixed page count.
  • The country in location.country is a lowercase ISO code.
  • An identifier that does not exist answers HTTP 404; a company without public postings answers 200 with an empty content.

questions

Frequently asked questions

Does the SmartRecruiters job board API need an API key?

No. Public postings are readable without a key. Keys are for the Customer APIs, which manage the company's own jobs and candidates.

Is there a rate limit?

SmartRecruiters documents general API limits of 10 requests per second and 8 at a time per credential, and states nothing separate for anonymous reads of the Posting API. Because descriptions need one call per posting, big companies take thousands of requests: spread them out and cache what you have read.

Can I get all SmartRecruiters jobs, from every company, at once?

No. The API answers for one company per request, and SmartRecruiters publishes no list of its customers. Our index reads 3,096 SmartRecruiters boards with open jobs every day (283,987 jobs on 20 November 2026); you can search all of them through our Apify actor or get them as a daily job data feed.

Is it allowed to use the SmartRecruiters job board API?

The API exists so that companies can show their jobs on their own sites and so that job boards can list them. It returns only what the employer has published. Read SmartRecruiters's documentation and terms for your use, keep request rates modest and link back to the original job for applications.
