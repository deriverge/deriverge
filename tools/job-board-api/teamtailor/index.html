Teamtailor Jobs RSS Feed

Teamtailor publishes each company's open jobs as an RSS feed at <company>.teamtailor.com/jobs.rss. The Teamtailor API needs a key from the company; the feed does not. Our index calls it for 1,116 companies a day and holds 16,846 open Teamtailor jobs (18 November 2026).

the endpoint

The Teamtailor job board endpoint

GET https://{company}.teamtailor.com/jobs.rss

  • Authentication: none for the RSS feed. The Teamtailor REST API needs a key that the company creates.
  • Format: RSS 2.0 with Teamtailor's own tt: elements for locations and department.
  • Pagination: the first 100 jobs by default. offset skips jobs and per_page sets how many come back.
ParameterWhat it does
offsetskip this many jobs, for example offset=100 for jobs 101 and on
per_pagejobs per response, for example per_page=200

Other endpoints of the same API:

  • https://api.teamtailor.com/v1/jobs: the REST API: a key from the company, an X-Api-Version header, 30 jobs per page at most and 50 requests per 10 seconds

Source: Teamtailor help: RSS feed. Checked 19 November 2026.

try it

Request and response

The board of Polestar, a Teamtailor board from our index, as an example. Replace polestar with the board you need.

curl

curl "https://polestar.teamtailor.com/jobs.rss"

Python

import requests
import xml.etree.ElementTree as ET

TT = "{https://teamtailor.com/locations}"
offset, items = 0, []
while True:  # the feed sends the first 100 jobs unless asked for more
    r = requests.get("https://polestar.teamtailor.com/jobs.rss", params={"offset": offset, "per_page": 100}, timeout=60)
    r.raise_for_status()
    page = list(ET.fromstring(r.content).iter("item"))
    items += page
    if len(page) < 100:
        break
    offset += 100

for item in items:
    places = [loc.findtext(TT + "name") for loc in item.iter(TT + "location")]
    print(item.findtext("title"), places, item.findtext("remoteStatus"), item.findtext("link"))

the data

Fields of a job

FieldMeaning
titlejob title
descriptionfull description, HTML escaped inside the XML
pubDatepublication date in RSS format
linkjob page; the number at its start is the job ID
guida stable unique ID of the job
remoteStatusremote status, for example none, onsite or hybrid
company_namecompany name (also the channel title)
tt:locations / tt:locationeach location with name, city, zip and country
tt:department, tt:roledepartment and role

which board

Finding a company's company subdomain

The company subdomain is the first part of <company>.teamtailor.com. Many companies run the career site on their own domain; the teamtailor.com address still works, and the page source loads assets from teamtailor-cdn.com.

Our list of 1,368 companies using Teamtailor shows the careers address of each one, and the address contains the identifier. The list is free to search and download as CSV.

in practice

What we learned reading it every day

  • The feed stops at 100 jobs unless you page with offset and per_page. Big employers have more; read until a response comes back short.
  • Teamtailor documents what the feed contains but not the element names; the names above are what the feeds send today.
  • Locations are inside tt:locations, one tt:location each. Read all of them; jobs in several cities list several.
  • remoteStatus is the most reliable remote signal in the feed. Do not guess remote work from the title.
  • The feed has no pay field. Pay, when published, is in the description.
  • Every Teamtailor career site has the feed, also those on a custom domain: <custom domain>/jobs.rss answers too.

questions

Frequently asked questions

Does the Teamtailor job board API need an API key?

Not for the RSS feed: it is public. The Teamtailor REST API does need a key, which only the company can create.

Is there a rate limit?

Teamtailor documents no limit for the RSS feed (its REST API allows 50 requests per 10 seconds). A company with up to 100 jobs is one call, bigger ones one call per 100 jobs. Keep your request rate modest.

Can I get all Teamtailor jobs, from every company, at once?

No. The API answers for one company per request, and Teamtailor publishes no list of its customers. Our index reads 1,116 Teamtailor boards with open jobs every day (16,846 jobs on 18 November 2026); you can search all of them through our Apify actor or get them as a daily job data feed.

Is it allowed to use the Teamtailor job board API?

The API exists so that companies can show their jobs on their own sites and so that job boards can list them. It returns only what the employer has published. Read Teamtailor's documentation and terms for your use, keep request rates modest and link back to the original job for applications.
