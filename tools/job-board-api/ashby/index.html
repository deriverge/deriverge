Ashby Job Posting API

Ashby publishes each company's job board through a public Job Posting API at api.ashbyhq.com. Our index calls it for 3,363 companies a day and holds 63,291 open Ashby jobs (20 November 2026).

the endpoint

The Ashby job board endpoint

GET https://api.ashbyhq.com/posting-api/job-board/{JOB_BOARD_NAME}

  • Authentication: none. The job board API is public.
  • Format: JSON, an object with jobs and apiVersion.
  • Pagination: none. One request returns every listed job.
ParameterWhat it does
includeCompensation=trueadds compensation to each job: a summary, the tiers and their components

Source: Ashby Public Job Posting API documentation. Checked 19 November 2026.

try it

Request and response

The board of OpenAI, a Ashby board from our index, as an example. Replace openai with the board you need.

curl

curl "https://api.ashbyhq.com/posting-api/job-board/openai?includeCompensation=true"

Python

import requests

r = requests.get(
    "https://api.ashbyhq.com/posting-api/job-board/openai",
    params={"includeCompensation": "true"},
    timeout=60,
)
r.raise_for_status()
for job in r.json()["jobs"]:
    pay = (job.get("compensation") or {}).get("scrapeableCompensationSalarySummary")
    print(job["id"], job["title"], job["location"], job["isRemote"], pay, job["jobUrl"])

Fields of a job

descriptionHtml / descriptionPlainthe full description in HTML and as plain text

compensationsummary and tiers of pay and equity (only with includeCompensation=true, and only when the company shows it)

which board

Finding a company's job board name

The job board name is the first part of the path on jobs.ashbyhq.com: jobs.ashbyhq.com/openai means openai. Job links on the company's own site carry ?ashby_jid=<id>.

Our list of 3,507 companies using Ashby shows the careers address of each one, and the address contains the identifier. The list is free to search and download as CSV.

in practice

What we learned reading it every day

  • Ask for includeCompensation=true: scrapeableCompensationSalarySummary is a short pay range, and compensationTierSummary adds equity and bonus.
  • A board answers HTTP 404 when the name does not exist. Names are case-sensitive in some boards; use the exact path from the job board address.
  • The organisation name is not in the API response. It is on the job board page, which titles itself "<Company> Jobs".
  • Big boards are large: OpenAI's 840 jobs with descriptions are about 15 MB. Cache the response and read each board once a day.

questions

Frequently asked questions

Does the Ashby job board API need an API key?

No. Ashby's Job Posting API is public and takes no key.

Is there a rate limit?

Ashby documents no rate limit for this API. One request returns the whole board, so a daily read is one call per company. Keep your request rate modest.

Can I get all Ashby jobs, from every company, at once?

No. The API answers for one company per request, and Ashby publishes no list of its customers. Our index reads 3,363 Ashby boards with open jobs every day (63,291 jobs on 20 November 2026); you can search all of them through our Apify actor or get them as a daily job data feed.

Is it allowed to use the Ashby job board API?

The API exists so that companies can show their jobs on their own sites and so that job boards can list them. It returns only what the employer has published. Read Ashby's documentation and terms for your use, keep request rates modest and link back to the original job for applications.
