before you start

How these APIs work

An applicant tracking system (ATS) is where a company posts its jobs and collects applications. Most of them publish each company's open jobs on a career site, and 8 of the 20 systems we read also document a public endpoint that returns those jobs as JSON, XML or RSS, made for career pages and job boards. Every guide links to the vendor's documentation and was checked against it and against a live response on the date shown.

Three things are the same everywhere:

  • One company per request. Every endpoint takes a company identifier (board token, site name, subdomain). No vendor publishes a list of its customers, so finding the boards is the real work. Our free lists of companies by ATS give you the identifiers.
  • Only published jobs. The endpoints return what the employer chose to show candidates: no applicants, no internal data, no personal data beyond what is in the job text.
  • Different shapes. Field names, locations, dates and pay come in a different form from each system, and some send descriptions only on a second call. The guides below show each one.

Frequently asked questions

Which ATS have a public job posting API?

Greenhouse, Lever, Ashby, SmartRecruiters, Recruitee, Personio, Teamtailor, Gem document a public endpoint for a company's published jobs (Recruitee only until 10 February 2027, when it starts requiring a token from each company). Workday, BambooHR, Breezy HR, Rippling, iCIMS, Eightfold, Softgarden, Hireology, Paylocity, Oracle Recruiting Cloud document no public job API for third parties; their jobs are on each company's career site.

Do I need an API key?

Not for reading published jobs from the endpoints in these guides, with one coming exception: Recruitee requires a token created by each company from 10 February 2027. Keys are needed for the other APIs of each system, which are meant for the employer itself.

How do I get jobs from all companies on all systems?

Call each company's board, normalise the fields and repeat every day, or use an index that does it. Ours reads 55,102 career sites on 20 systems daily (2,022,704 open jobs on 18 November 2026); search it through our Apify actor or take it as a daily job data feed.
