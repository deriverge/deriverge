Personio XML Job Feed

Personio publishes each company's open positions as a public XML feed at <company>.jobs.personio.de/xml, made for job boards and career pages. Our index calls it for 2,146 companies a day and holds 21,340 open Personio jobs (18 November 2026).

the endpoint

The Personio job board endpoint

GET https://{company}.jobs.personio.de/xml

  • Authentication: none; Personio's FAQ says the feed needs no credentials. The company has to switch the feed on (Settings, Recruiting, Career Page, Activations).
  • Format: XML: a <workzag-jobs> root with one <position> per job.
  • Pagination: none. The feed lists every published position.
ParameterWhat it does
languagede, en, fr, es, nl, it or pt: positions in this language of the career page. Jobs not translated into it can come back without descriptions

Other endpoints of the same API:

  • https://{company}.jobs.personio.com/xml: the same feed for accounts on the .com domain

Source: Personio developer hub: XML job feed. Checked 19 November 2026.

try it

Request and response

The board of 1KOMMA5°, a Personio board from our index, as an example. Replace 1komma5grad with the board you need.

curl

curl "https://1komma5grad.jobs.personio.de/xml"

Python

import requests
import xml.etree.ElementTree as ET

r = requests.get("https://1komma5grad.jobs.personio.de/xml", timeout=60)
r.raise_for_status()
for pos in ET.fromstring(r.content).iter("position"):
    sections = [d.findtext("value") or "" for d in pos.iter("jobDescription")]  # HTML per section
    print(pos.findtext("id"), pos.findtext("name"), pos.findtext("office"), pos.findtext("createdAt"))

which board

Finding a company's company subdomain

The company subdomain is the first part of the job page address: 1komma5grad.jobs.personio.de means 1komma5grad. Job links look like <company>.jobs.personio.de/job/<id>.

Our list of 2,245 companies using Personio shows the careers address of each one, and the address contains the identifier. The list is free to search and download as CSV.

in practice

What we learned reading it every day

  • Without language the feed uses the company's default language and every position has its description. With language=en, positions written only in German came back with empty <jobDescriptions> in 36 of 37 cases we tested.
  • A company with no open positions returns an empty <workzag-jobs></workzag-jobs>, not an error.
  • A closed account redirects to personio.com. Treat a redirect away from *.jobs.personio.de as "no such company".
  • Personio's robots.txt applies to the feed. Read it first and respect HTTP 429: Personio rate limits automated readers.
  • There is no posting date apart from createdAt, the date the position was created in Personio.

questions

Frequently asked questions

Does the Personio job board API need an API key?

No. The XML feed is public for every company that publishes jobs on a Personio career page. Personio's REST API, for the company's own HR data, needs credentials.

Is there a rate limit?

Personio documents no number. Its FAQ suggests job boards sync the feed at least once an hour; in practice it answers very fast readers with HTTP 429 and its robots.txt sets the rules for automated access. Back off when asked to.

Can I get all Personio jobs, from every company, at once?

No. The API answers for one company per request, and Personio publishes no list of its customers. Our index reads 2,146 Personio boards with open jobs every day (21,340 jobs on 18 November 2026); you can search all of them through our Apify actor or get them as a daily job data feed.

Is it allowed to use the Personio job board API?

The API exists so that companies can show their jobs on their own sites and so that job boards can list them. It returns only what the employer has published. Read Personio's documentation and terms for your use, keep request rates modest and link back to the original job for applications.
