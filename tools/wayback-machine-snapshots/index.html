how it works

How the snapshot finder works

The Internet Archive's Wayback Machine has saved copies of web pages since 1996. For every URL this page asks the archive's Availability API three questions: the capture closest to 1 January 1996 (the first one), the capture closest to today (the latest one) and, if you pick a date, the capture closest to that date.

The Availability API returns one capture per question and only captures that loaded successfully, and it often reports nothing even for well archived pages. When it does, the cell links straight to the Wayback Machine, which jumps to the first, latest or closest capture itself. calendar shows all captures by day and all URLs lists every archived address under the domain.

Why no count of captures per year here? Counts and full lists come from the archive's CDX API, which does not accept requests from other websites' pages, so a browser tool cannot read it. The calendar view in the Wayback Machine shows the same information visually.

questions

Frequently asked questions

How do I find when a website was first archived?

Enter the domain above. First capture shows the date of the oldest snapshot when the Availability API reports it; otherwise open first capture takes you to the oldest capture in the Wayback Machine, where the date is in the address and the toolbar.

How do I see a website as it looked on a specific date?

Pick the date in closest to date. The table links the snapshot nearest to that day; the Wayback Machine may pick a capture a few days or months away when nothing was saved on that day.

Why is there no date for a page that is archived?

The Availability API answers from a separate index, skips captures that were redirects or errors and is sometimes slow to answer at all. The links in the table still open the right capture, and the calendar shows every capture the Wayback Machine has.

How do I list every archived page of a domain?

The all URLs link opens that list in the Wayback Machine. The Wayback Machine shows the first and last capture of each URL in that list.

How many snapshots does a site have per year?

The calendar view in the Wayback Machine shows it visually. The Internet Archive also documents its CDX API for researchers who need the counts as data.

Is this tool free?

Yes. It runs in your browser against the Internet Archive's public API. Consider supporting the Internet Archive, which keeps the Wayback Machine running.
