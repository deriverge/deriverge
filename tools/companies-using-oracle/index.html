// check it yourself

How to tell if a company uses Oracle Recruiting Cloud

Open any job on the company's careers page and look where the Apply button leads. A company uses Oracle Recruiting Cloud when:

  • The career site is <pod>.fa.<region>.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1.
  • Job links contain /job/<number>.

The public job feed of a Oracle Recruiting Cloud board is at https://<pod>.fa.<region>.oraclecloud.com/hcmRestApi/resources/latest/recruitingCEJobRequisitions. It needs no key and is what our index reads every day.

Not sure which system a link belongs to? Paste it into the ATS detector, or search the company by name on the ATS overview.

// about the data

About Oracle Recruiting Cloud and this list

Oracle Recruiting Cloud is part of Oracle Fusion Cloud HCM, used by large enterprises, banks and public institutions. Career sites live on Oracle Cloud hosts such as <pod>.fa.<region>.oraclecloud.com.

How this list is made. We find Oracle Recruiting Cloud career sites in the public Common Crawl web archive and read each board's public job list every day for our job index. A company is listed when its board answered with a company name; companies with a live board but no openings today are included with 0 jobs. The main country is the country with most of the company's job locations. This is a sample of employers we could find, not Oracle Recruiting Cloud's full customer list. The list holds company names and public career pages only, no personal data. If your company should not be here, write to info@deriverge.com.

How many companies use Oracle Recruiting Cloud?

We know of 903 companies with a public Oracle Recruiting Cloud career site, and 890 of them had open jobs on 11 October 2026. Oracle Recruiting Cloud's real customer count is higher: many employers keep their board unlisted or hire without a public board.

Click Apply on one of its jobs and check the address. The career site is .fa..oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1.
